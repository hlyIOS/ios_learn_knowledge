# 基准布局方向（环境层）是什么？

> 补充说明 · 参见 [语义属性与布局方向的关系](./SemanticAttribute与LayoutDirection的关系.md)

---

## 一句话解释

**「环境层 → 基准布局方向」** 指的是：在还没考虑某个控件自己的 `semanticContentAttribute` 之前，**整个 App / 当前界面默认应该按 LTR 还是 RTL 来布局**。

可以把它理解成「大背景规则」——系统先定好「今天餐厅规定从左读还是从右读」，然后再看每个控件自己的标签要不要例外。

---

## 三个输入分别是什么？

### 1. 系统语言

用户在 **设置 → 通用 → 语言与地区** 里选的语言。

| 语言类型 | 默认基准方向 |
|----------|-------------|
| 中文、英文等 | LTR（从左到右） |
| 阿拉伯语、希伯来语等 | RTL（从右到左） |

这是最主要、最常见的来源。

---

### 2. App 设置

App 自身的本地化与布局相关配置，例如：

- App 支持哪些语言（Localization）
- `UIApplication.shared.userInterfaceLayoutDirection` — App 全局的布局方向
- 是否在代码里 override 了 App 级别的方向（较少见）

App 会结合「系统语言 + 自己支持的语言列表」决定实际走 LTR 还是 RTL。

---

### 3. Trait Collection

`UITraitCollection` 是 iOS 描述**当前界面环境**的对象，其中包含 `layoutDirection` 属性。

常见影响方式：

```swift
// 某段界面强制 RTL（例如预览、特定页面）
let rtlTraits = UITraitCollection(layoutDirection: .rightToLeft)
setOverrideTraitCollection(rtlTraits, forChild: childVC)
```

- 父 ViewController 可以 override 子页面的 trait
- 不同界面可以有不同的布局方向环境
- `effectiveUserInterfaceLayoutDirection` 会综合这些 trait 信息

---

## 「基准布局方向」具体指什么？

就是上面三者综合后得到的**默认方向**，还没应用某个 view 的 semantic attribute 时：

```swift
// 这就是「基准布局方向」——代表「当前环境默认怎么走」
UIView.userInterfaceLayoutDirection(for: .unspecified)
// 或
UIApplication.shared.userInterfaceLayoutDirection
```

| 场景 | 基准方向 |
|------|----------|
| iPhone 系统语言设为阿拉伯语 | `.rightToLeft` |
| iPhone 系统语言设为中文 | `.leftToRight` |
| 中文系统，但某 VC 被 override 成 RTL | 该 VC 内基准为 `.rightToLeft` |

---

## 和 semantic attribute 怎么配合？

```
基准布局方向（环境层）
        +
semanticContentAttribute（语义层）
        ↓
effectiveUserInterfaceLayoutDirection（最终结果）
```

| semantic attribute | 在 RTL 基准环境下的结果 |
|--------------------|------------------------|
| `.unspecified` | 跟随基准 → `.rightToLeft` |
| `.playback` | 不翻转 → `.leftToRight` |
| `.forceLeftToRight` | 无视基准 → 强制 `.leftToRight` |

---

## 一个完整例子

假设：**系统语言是阿拉伯语**（基准 = RTL）

```
环境层：系统语言 = 阿拉伯语 → 基准方向 = RTL
                ↓
普通按钮 (.unspecified)     → 最终 = RTL ✅ 随语言翻转
播放按钮 (.playback)       → 最终 = LTR ✅ 不翻转
某区块 (.forceLeftToRight) → 最终 = LTR ✅ 开发者强制
```

---

## 记忆要点

> **环境层 / 基准布局方向** = 当前 App 界面默认的 LTR/RTL 规则，主要由系统语言决定，App 配置和 Trait Collection 可以局部覆盖；`.unspecified` 的控件会跟着它走，其他 semantic 值可能覆盖或反转它。
